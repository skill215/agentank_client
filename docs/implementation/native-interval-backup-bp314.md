# BP314：未知转移的区间传播 POC

## 结论

独立小矩阵验证表明：不必把未知转移变成一个猜测分，也不必总是丢弃整个搜索层。未知值保持区间，通过正确量词传播后，有时仍可严格区分动作。

本轮仅新增开发侧算法和UT，没有修改production、没有运行ACTIVE对战，不报告胜率或性能提升。

## 可重复证据

运行 `node tools/agentank/diagnostics/interval-backup-poc.js`：

- 枚举端点来自{-1,0,1}的全部六种整数区间，构造全部1,296个2×2矩阵。
- 穷举10,000个区间内整数填充，独立计算每个具体矩阵的max-min。
- 所有具体值均落在传播区间内。
- 230个矩阵产生严格纯动作证书，错误证书0。
- 5项UT通过，包括chance、ε污染、负数向外取整、量词顺序、未知分支、空支持和安全整数溢出。

这些是合成数学测试分母，不是游戏根覆盖率。初次UT发现Math.ceil负分数产生-0；已在区间构造时统一为0，未放宽断言。

## 语义

MIN节点分别取所有子节点lower/upper的最小值；MAX同理取最大值。已知固定概率的chance逐端点加权，向外取整。ε污染将worst和nominal expectation保守组合；概率不完整不能擅自重新归一化为完整支持。

只有某动作lower严格大于所有其它动作upper，才能输出此有限纯动作模型内的严格选择证书。未知分支不删除、不当死亡，不设置Hard或Proof。

示例：动作A对两个响应为[3,3]、[4,4]；动作B为[-10,10]、[1,1]。B的最坏值区间是[-10,1]，A为[3,3]，故A仍严格更优。若B第二格改为[8,8]，则不再能够确定优胜动作。

共同隐藏世界、观察等价类和跨分支策略约束不能通过独立MAX放松成可实际执行的策略。当前POC只验证显式纯动作矩阵，未处理这些游戏信息结构。

同时行动混合矩阵也不可替换成纯max-min：Matching Pennies纯max-min为-1，混合均衡为0。后续StageMatrix需要独立的区间/策略证书，不复用本POC的纯策略结论。

## 接入阻碍：尚无可靠production效用范围

生产policy-search里的VALUE_MIN/MAX为±32000，但terminalUtility可返回±100000，leaf还叠加pathScore和history调整。它们不能作为未知转移的全局值界。

当前Fast不支持分支返回-22000，Hard不完整返回启发叶减6000。这些是现有policy启发分，不是未知真实值的严格界。本轮不改变这些值，也不将现有不完整rootScore包装成exact区间。

即使找到合法全局值域，有限深度评分区间也不是完整对局胜负证明。深度截断、预算截断、规则未知、Hard支持不足须分别标记；不得把最后一类等同于已经证明死亡。

## 下一步顺序

1. 审计当前有限深度搜索的值域和哨兵使用：terminal、leaf、path、history、robust/nominal各自边界；用UT重现潜在截断，暂不混改决策策略。
2. 明确保守有限界或显式无界表示、整数溢出及取整规则。
3. 独立影子区间搜索保留现有动作域、深度和量词，未知转移仅输出界，不能继续沿部分更新的FastState递归；必须回滚。
4. 在BP313同一批根测量“可区分动作数量/宽区间残留/耗时”，动作仍由原production选择。证明覆盖不足则停止，不放宽界以制造收益。
