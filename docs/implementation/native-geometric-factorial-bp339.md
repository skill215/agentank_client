# BP339：搜索调度与几何入口的2×2因果拆分

## 结论

拒绝“远距离、无射线、敌方眩晕即取消搜索提案”的入口改动。它在当前和分层两种搜索下均降低本批整局得分，且均使星数负局增加15局。BP337将该入口描述为上游问题，是基于小开发集的过早推广；触发条件与战术接触命名不一致，并不证明这部分计算没有行为价值。

分层128本身没有复现组合候选的大幅退化：得分50.78125%，相对原版50%增加0.78125个百分点；单方击毁不变，被击毁少10局。但差异不显著，仍是待验证候选，不是已证明优胜版本。

## 实验边界

复用BP338固定64场景、两座位、双方stun。旧CURRENT和组合候选各128局按文件SHA-256复用；本轮只新增CURRENT_GEOMETRIC、LAYERED128各128局。四臂总512局证据，本轮运行256局。

运行前核对BP338冻结的production tree、诊断执行器/入口/验证工具源码哈希；场景按id直接载入并核对fingerprint。不重新抽样、不改128转移预算/3层上限、不修改评分。完成后再次核对生产tree和旧结果哈希。

本批结果已在BP338公开，属于后续归因诊断，不是新Holdout。统计p值仅描述场景配对差异，不作确认性或多重比较后的显著性宣称。

每个随机化单位是同场景两个座位得分差之和，不把换位局当作独立样本。没有任何比较达到p<0.05；不能将0.0559称为已经显著。可见负向点估计已足以否决推广要求，但不足以估计真实总体损害幅度。

入口限制在原搜索上产生15负→胜、19胜→负、4负→平、2胜→平、9平→负；净减少7.5得分。分层上产生13负→胜、25胜→负、2负→平、1胜→平、4平→胜、6平→负；净减少12.5得分。

仅分层相对原版产生24负→胜、19胜→负、6负→平、7胜→平、3平→胜、10平→负；净增加1得分。这个接近中性的总结果仍包含大量正反翻转，不能声称逐场非退化。

## 解释及局限

1. 组合候选的-8.984375个百分点，可分解为原入口下分层+0.78125，再加分层下入口-9.765625。这支持优先撤销入口限制，而不是否定完整层提交。
2. 限制入口在两个搜索下都增加15局星数负，星差分别减少49和52；说明丢失的搜索提案与目标竞争有关。不是只有近距离击毁才体现搜索价值。
3. 仅分层FIRE少198次，但单方击毁仍34，被击毁少10；不能靠开火次数判断其优劣，也不能把所有击毁归因于子弹命中。
4. 被击毁减少与星数负增加是总体分布，不能未经逐局核对就说每个救活局都转为星数负。
5. 尚未证明具体机制是朝向、追星路径、重复pose还是长期目标承接。当前证据只定位到删除搜索提案的行为影响；不应立即补新的距离/朝向启发式。

## 下一步建议

结束几何入口限制这条候选分支，不继续修改距离阈值。保留原入口；分层128作为完整层调度候选保留，但不宣称胜率提升。

优先从已有四臂压缩动作流提取“仅入口导致星数胜/平转负”的首次分歧，重建共同根，比较原搜索提案与无提案时的导航动作及目标进度。目的不是继续证明远距离搜索应禁用，而是明确当前搜索实际承担哪些导航/目标决策责任，避免再次在优化边界时删掉有效行为。新诊断只需紧凑根，不再扩跑整局或扫描参数。

分层调度的性能资格独立进行匹配输入标定；行为改进则依据上述所有权证据设计，不把更深或更快直接等同于胜率更高。
