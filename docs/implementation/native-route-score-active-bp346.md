## 结论：NOT_QUALIFIED，保留实验，不合入生产

路线评分候选在固定64场景128局上单方击毁34→40、单方被击毁44→39，但综合得分仅50%→50.78125%。场景级配对随机化p=0.946106，没有总体优势证据。

## 不能只看总胜率或总死亡数

23个胜→负中：

- 13个单方击毁胜变单方被击毁；
- 5个星数胜变单方被击毁；
- 4个单方击毁胜变星数负；
- 1个星数胜变星数负。

所以后续需要分析18个新单方死亡与5个新星数负，而不是因总被击毁减少就忽略安全/接触时机退化。

23个负→胜中：10个单方被击毁变单方击毁，7个被击毁变星数胜，4个星数负变单方击毁，2个星数负变星数胜。

平局打破也有两面：11平→胜中9个成为击毁胜；8平→负中5个成为单方被击毁。因此攻击改善不能简单解释为“开火更多”：FIRE只多7次，而且击毁还可能由炸弹造成，不能当作弹丸转化率。
