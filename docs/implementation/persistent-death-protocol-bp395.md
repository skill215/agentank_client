# BP395：R71–R80 持续死亡单步反事实预注册

延续高效调优协议，不修改生产代码、Hard、候选系数、场景、种子或旧产物。只使用本地 bomb-phase 校准模拟器和确定性 V1 时钟。所有结果均为已见地图上的诊断，不是平台胜率或新盲测。

## 冻结范围与十轮

从 BP394 的 persistentDeathRegressions 全选 R15 的 7 个、R29 的 8 个地图／座位组合（去重共 14 个），每个组合取已有五个种子，合计 75 个候选对局。首次分歧实验包含全部五个种子，避免只记录有害结果；尾部实验仅包含原候选单方死亡且原 baseline 不单方死亡的退化事件，不事后扩样。

| 轮次 | 候选 | 单步干预 |
|---|---|---|
| R71 / R72 | R15 / R29 | 首次动作分歧帧恢复原 baseline 动作 |
| R73 / R74 | R15 / R29 | 首次动作分歧帧枚举合法动作 |
| R75 / R76 | R15 / R29 | 最后一次决策之前 2 步枚举合法动作 |
| R77 / R78 | R15 / R29 | 最后一次决策之前 5 步枚举合法动作 |
| R79 / R80 | R15 / R29 | 最后一次决策之前 9 步枚举合法动作 |

尾部索引严格为 decisionCount - 1 - offset，帧号必须与决策索引相等。不存在的根如实标记，不移动窗口。首次分歧取双方流仍存在时第一个候选动作或参数差异；对手此前流必须一致。

## 执行与门禁

先冻结源码、样本、模块与输入文件 SHA256，重跑 75 局验证逐动作、参数、分析终局、搜索工作量与 BP394 一致。回放记录每个根的 Hard、finalGate、Risk 标签及搜索原因。然后按固定公式生成并冻结全部十轮计划，再运行分支。

只枚举 Hard=0 且 finalGate.finalAllows 的动作，排除 NONE 和有参数的 teleport。恢复 baseline 动作若不合法则记录 blocked，绝不绕过 gate。同一地图、种子、座位、候选、帧、动作的分支跨轮复用，按唯一 key 计实际对局数。每个可行根运行强制原动作的 no-op，对整局语义和搜索工作量检验等价；全部通过后才运行替代动作。无法 no-op 的根必须显式记录覆盖，不把缺失称为通过。

每条替代分支必须 forceFrameSeen=1、forceApplied=1、forceOriginalAction 与原根一致，干预前双方动作和参数完整一致，同帧对手动作及干预前根状态一致；只改变一个动作，后续沿用相同候选。双方 errors/timeouts、rootRestoreFailures、hotAllocations 必须为 0。运行错误不计完成轮次；检查点逐行哈希、身份和 job 一致，禁止静默覆盖。

## 指标与解释

恢复动作轮报告有资格分母、阻止数、得分变化、原退化挽回及非退化损坏。Oracle 轮分别报告存在得分改善的局数、存在避免单方死亡的局数，两者可来自不同动作；保留每个分支完整终局。未改变的原轨迹始终包含在 oracle 比较中，不合法的原动作也只能作为观察对照，不能声称已强制验证。

每轮每局至多计一次挽回；跨窗口并集按候选+地图+座位+种子去重，不把收益相加。预注册结论是 MECHANISM_RECOVERABLE / NO_RECOVERY_OBSERVED 或 RESTORE_HELPS / RESTORE_NO_NET_GAIN；无候选晋级、生产采用或参数再搜索。死亡前窗口与最佳动作都使用事后信息，收益仅为模拟器内经验上限。相同初始种子不能保证分歧后随机抽样逐次对齐；stun 等规则仍未全量校准。
