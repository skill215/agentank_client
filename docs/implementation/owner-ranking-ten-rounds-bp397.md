# BP397：R91–R100 动作排序与风险标签

完成 **10 轮，新执行 1664 局**，复用本批相同候选 0 行。包括 384 局生产／R15／R29 等价预检。全量双对照通过者：无。生产默认、Hard、风险准入和 finalGate 均未改动。

## 冻结设计

本批保持 R15／R29 路径系数，仅改变 owner 内已准入动作的排序：风险支配优先、严格接纳优先、去掉意图加分、去掉 nominal 平局项、主分数平局保留当帧 incumbent。每种机制分别用于两个父候选。没有把离线最优动作、死亡位置或地图 ID 写入规则。

沿用 BP396 的64地图开发集（128局）及128地图验证集（256局），manifest 明确绑定上批样本和哈希。验证地形排除开发及 BP394 全部192张证据地图。全部历史地图曾参与总体分析，属于规则开发隔离而非全新盲测。

每轮必须同时相对生产和父候选达到开发净局分 ≥2，单死、换位双负均不增加，节点比 ≤2，机制确实改变比较／加分；通过后才跑验证和全量，两个对照均须正收益且非退化。完整预注册见 [owner-ranking-protocol-bp397.md](owner-ranking-protocol-bp397.md)。
