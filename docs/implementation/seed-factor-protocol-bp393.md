# BP393：R51–R60 种子与场景变换分离实验预注册

目的：解释 BP392 的压力退化，不再扫描系数。R15/R29 直接复用 BP392 已等价验证的独立源码模块，生产默认、Hard、预算、V1 时钟、炸弹 phase 校准均不变。不调用官方接口、不提交推送、不启用子 agent。

BP392 同时改变了场景几何/星时间与由指纹派生的随机种子，不能直接归因为几何或时间变化。本批固定其三个 64 父地图集合（共 192 个不同原地图），补齐每组的 2×2 场景/种子对照。原场景+原种子、变换场景+BP392 种子引用旧缓存；新执行另两格。所有结果已知集合上的机制诊断，不是新历史盲测。

另一组种子是 sha256("bp393-independent-seed-v1:" + parentFingerprint) 前 8 位转 uint32，出结果前冻结。候选与原始策略同图、同初始种子、双座配对；不会声称轨迹分岔后的随机调用仍逐次对齐。

种子在诊断层构造 AgenTankSimulator 时显式传入；场景指纹仍包含真实场景内容和干预种子，不伪造指纹、不修改旧宿主文件。逐局记录请求种子、传入构造器的生效种子与宿主默认派生种子，三者用途分明。比较时不将 VM 宿主常量当实测，本批均原生运行，采集实际搜索、恢复和热分配。

准备阶段：按 sha256(bp393-preflight-v1:parentId) 选 16 个父地图；原场景与对应 BP392 变换场景各双座，baseline/R15/R29 共 192 局。显式传入原来默认派生的种子，要求与各自旧缓存逐动作、参数、终局、计数及搜索工作量完全一致。预检不计十轮。

五个环境块各跑一次原始策略基准，供两候选复用；新执行共 3456 局 + 192 局预检 = 3648 局。旧结果只是引用对照，绝不计新执行。逐局 SHA-256 检查点、源码与输入身份冻结、每进程推进一个阶段；完整产物不可覆盖，执行错误修复后重跑，不计有效轮次。

各轮保留压力门：净局分至少 +2，单方死亡负局与换位双负均不增加，节点 ≤2 倍，对局 error/timeout、restore、hotAllocation 为 0。门槛用于描述压力稳健性，不自动晋级生产。输出逐组四格收益及安全计数；分别计算种子主效应（原场景上换种子）、场景主效应（原种子下变换）及交互差。按父地图聚类做 2000 次配对 bootstrap，仅作描述性区间，不以事后阈值宣称因果占比。

补充记录候选首次改变动作附近的搜索入口、历史动作、转向次数、双方星数、选行动作和搜索节点。只用于已观察退化案例的定位，不把事后挑例当普遍机制证据，也不强制未获 Hard 允许的动作。
