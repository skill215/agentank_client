## 触发覆盖率与成本

SHADOW 和 ACTIVE 均检查 2,755 个根：3 个证书通过，只有 1 个需要改变动作；另外 2 个原动作已经是 FIRE。

| 指标 | OFF | SHADOW | ACTIVE |
|---|---:|---:|---:|
| V2 总运行时间（本地 µs） | 3,191,909 | 3,554,363 | 3,317,166 |
| 证书计算累计（µs） | 0 | 306,961 | 265,072 |
| 证书单根 P95（µs） | — | 211.235 | 167.218 |

相同动作输入下 SHADOW/OFF 总耗时比为 1.11355，即本次约 +11.4%。这只是顺序运行、单批本地观测，受 JIT/噪声影响；不是固定五批微基准，也不能解释为官方平台 3000ms 预算比例。ACTIVE 与 OFF 的路径发生变化，不应用其总时间差直接宣称优化。

目前每帧克隆并展开完整响应明显浪费：证书通过率 3/2755，仅约 0.109%；真正覆盖 1/2755。不能原样放进 production 热路径。

## 下一步建议

先优化执行规模，而不是扩大对战数或放宽证书条件：

1. 原动作已经是 FIRE 时无需额外证书决胜。
2. 入口/观察明确不支持时，在克隆前返回。
3. 利用证书必须包含成功 NONE 响应这一必要条件，做廉价的射线/行动后星差必要条件检查；不能用近似条件假设成功，只能提前排除不可能支持的根。
4. 对剩余根才展开完整敌方响应。以本轮逐帧证书和动作结果作等价基线，证明未漏掉任何可改变动作的支持根，再做同输入性能标定。

以上应是语义保持的早拒绝优化，不修改风险阈值、胜负语义或响应域。通过后再进入更大范围验证。
