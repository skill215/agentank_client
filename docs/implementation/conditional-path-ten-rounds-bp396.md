# BP396：R81–R90 当帧条件式路径评分

完成 **10 轮、新执行 1664 局**，复用本批相同候选对局 0 行，包含 384 局生产／R15／R29 等价预检。通过全量双对照门槛的诊断候选：无。生产默认、Hard、Risk 和旧候选保持不变。

## 假设和隔离

依据 BP395 的单步证据，测试五个只依赖真实当前根状态的条件，每个用于 R15、R29 各一次：刚释放 stun、自身仍眩晕、连续转向至少一次／两次、星数落后。条件命中时仅本次搜索恢复生产原始路径评分，其余根使用父候选评分。条件在 prepare 入口冻结，不读取未来轨迹、死亡窗口或 baseline 动作。

开发集为64张不同地形地图、128局，包含上一批全部证据地形及一般地图；验证集128张地图、256局，排除开发集及 BP394 全部192张证据地图。这里是本轮规则开发隔离，历史地图都曾总体分析，不能称为全新盲测。

开发要求同时相对生产和父候选净局分 ≥2；验证／全量要求同时 >0。两组对照都不得增加单死、换位双负，节点比均不得超过2。未过开发就停止该轮。协议在执行前冻结，见 [conditional-path-protocol-bp396.md](conditional-path-protocol-bp396.md)。
