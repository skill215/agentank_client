# BP121–BP122：策略身份修复成立，depth-2标量所有权被因果否决

## 结论

BP120把攻击路线只放进第一步，208个完整候选全部被Minimax反驳。BP121改为比较两条真正不同的
branch-local policy：incumbent分支保持原续写，ATTACK分支每层重新规划同一语义敌方目标下的
`ATTACK_APPROACH`。具体射位可以随状态变化，但策略身份不再互相污染。

这个结构修复是有效的：固定16场景Shadow中，完成的213次比较产生32个严格优势，而BP120为0。
但BP122把这些优势作为ACTIVE动作证书后，得分从9.38%降至7.81%。因此正确结论是：策略身份是
必要条件，短视界标量优势仍不是动作所有权的充分条件。

## BP122 ACTIVE因果结果

ACTIVE只接管本帧新生成的严格优势，接管前再次经过Physical Hard和FinalActionGate。19个证书全部
实际覆盖，FinalGate拒绝为0；轨迹变化后证书数从Shadow的32降为19，这是正常的在线因果反馈。

转移只有一个改变胜负：`DRAW→V1_WIN`。但终局形态还显示两局从被击毁败局改善为存活到128帧，
三局从128帧败局恶化为提前被击毁。这个所有者并非处处反向，而是局部收益与灾难风险没有被当前
标量区分。

关键反例是`mat_I52zYeSqz1RCC3Vqs` seat 0：第23帧仅凭`-2271→-2124`的147点depth-2优势把
`GO`改成`TURN_RIGHT`，最终把128帧同星平局改成第94帧炸弹击毁。FinalGate只验证被发出的第一动作；
它没有证明后续ATTACK策略在炸弹deadline前仍然可活。

## 架构判定

保留：

- 语义敌方target与`ATTACK_APPROACH`策略身份；
- incumbent/attack分支独立续写；
- 稀疏成对策略搜索作为Shadow证据服务；
- 每次诊断覆盖前的Hard与FinalGate复核。

拒绝：

- 把depth-2战术叶的单一标量严格优势称为“严格证书”；
- 把19次BP122覆盖接入Production；
- 在事件/终局语义缺失时先加深搜索或调整优势阈值。

下一步应在同一双策略搜索中增加独立的事件结算与terminal/nonloss区间：候选只有在完整事件/终局
下界严格高于incumbent上界时才能拥有动作；已经提交的炸弹和弹丸必须越过短decision horizon继续闭合
到deadline。机器摘要见
`config/engine-v3/base-policy-kernel-bp121-bp122-semantic-attack-policy-evidence.json`。
