# BP349：冻结导航候选的192场景外部开发验证

## 结论

NOT_QUALIFIED。完成768局：CURRENT与冻结BP348候选各384局。候选综合得分53.515625%→55.338542%，提升1.822917个百分点，场景配对双侧p=0.585171；单方击毁130→127。未达到预注册的+3pp、p<0.05及击毁不下降三个条件，不接入生产，不在本轮调参重跑。

这说明静态导航进度细化有改善星数终局的点估计，但目前不能证明它是整体胜率恢复的有效方案，更不能把它当作攻击能力提升。没有显著差异不等于证明两者等效。

## 冻结与分母

- 排除V3修复832场景及BP348的64场景，从剩余347个合格历史场景中固定哈希选192个。
- 盐：`bp349-navigation-family-frozen-external-192`。按场景fingerprint选取，不读取历史胜负用于抽样。
- 每场景两个座位、两个模式，共192×2×2=768局，双方stun；按场景交替模式执行顺序。
- BP348候选源码哈希和生产树在运行前后校验一致；没有改变阈值、搜索预算或策略参数。
- 这是本轮开发集外验证，但历史池曾被其他实验使用，不能称全新盲测。p值也不代表排除了长期多次实验的选择偏差。
