# BP359：从状态生成受限弹道终局依据

## 交付与结果

新增`inspectBallisticWitness`，在每个联合动作已经执行、星已收集、弹丸尚未推进的位置检查真实分支状态，而不是读取场景白名单或压力测试胜率。

6个领先根的全部45个响应返回FRESH_SHOT_CLEAR_HIT；同星根10个响应全部返回NONPOSITIVE_SETTLEMENT_MARGIN。有限枚举结果不变，7个根仍保持全局INCOMPLETE，未清零8192，没有接管动作。

## 可计算条件

每个分支检查：

- 使用动作执行和拾星后的星数，要求我方严格领先；
- 没有当帧到期的已知炸弹；
- 若敌方已死，记录这一单调事实；否则敌方当前无有效护盾；
- 存在已创建、活跃、属于我方、created==当前frame的新弹丸；
- 从实际弹丸位置沿方向最多推进平台配置步数，可以抵达敌方实际后继位置；
- 命中路径无墙/土，不先经过活着的我方坦克。

不使用tactical高分、距离奖励、expectedValue或搜索完成深度作为证据。函数只扫描固定数组，不分配数组或对象，不改状态；整个诊断runner仍有克隆和日志分配，尚不是生产性能验收。

## 条件性论证

在以下规则范围内，上述命中见证支持额外敌弹不取消敌方死亡：

1. 进入弹丸阶段时我方弹丸已存在，之后不会因我方死亡被撤销；
2. 弹丸互相穿过，不互相抵消；
3. 在这一阶段，额外敌弹不能产生墙、土、护盾或新坦克，也不能移动敌方；
4. 额外弹丸可能击毁坦克、消耗护盾或移除土；被证明的命中射线本就不依赖土的存在，敌方本就无盾；
5. 若额外弹丸先杀死敌方，目标已经实现；否则我方弹丸沿无遮挡射线击毁敌方；
6. 结算在相关弹丸推进完成后发生，双方死亡也按已计算的有利星差获胜；此阶段没有改变该星差的事件。

这是一条有前提的局部单调性论证，不是声称任何FIRE均成立。BP355的落后/护盾反例与BP356的提前结算反例说明这些前提不能删除。

## 为何还不签发生产证书

检查器目前验证的是**给定分支进入弹丸阶段后的几何事实**。它没有单独证明所有未知世界都能进入相同的安全相位，也没有自动核验上述规则前提在全部平台动作/效果组合中成立。

仍需闭合：

- 行动前事件和未知实体不能阻止我方发射；本轮没有覆盖未知炸弹或其他gap；
- 敌方因已有隐藏弹丸不能FIRE时，应映射到已覆盖的无射击分支，需验证状态/事件影响而非只删动作；
- 所有合法动作、chance以及根到相位入口的支持覆盖；
- 本地模拟器与生产专用kernel相位/碰撞差异的明确适用边界；
- 物理容量与预算中断不能被“理论上存在射线”覆盖。

所以没有把BP357三类证书硬写VERIFIED，也没有修改全局informationComplete。下一步应检查从root到弹丸阶段的适用前提，再组合为Shadow的完整局部证据；不是继续扩大随机样本。
