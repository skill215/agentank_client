# BP142：单次响应偏离恢复8个局部证书，但没有攻击资格

## 搜索合同

BP141证明继续添加固定手写策略没有价值。BP142以`DIRECT_PURSUIT`为baseline，在每条已观察世界线中
最多允许一次非baseline动作；偏离后剩余horizon恢复direct。选择baseline时可以把偏离资格推迟到下一
状态。缓存身份显式加入`deviationAvailable`，所以同一物理状态的“还能偏离”和“已经偏离”不会混合。

我方动作只能依赖当前状态，不能读取同帧敌方动作或ChanceOutcome。敌方动作、Chance和三种移动规则
世界仍全部展开。candidate和incumbent分别使用同一策略类求最优值，候选证书仍要求所有规则世界最坏值
严格更高并且同敌方列逐点支配。

## 性能标定

4096和8192节点下105个实例全部预算中断；16384仍全中断。32768首次暴露2048槽TT容量瓶颈，扩大为
固定8192槽后容量失败归零。四根在65536下完整但需要800,615节点。

随后加入精确maximin行剪枝：某偏离动作只要一个敌方列或Chance已使其值不高于当前最佳，就不可能
赢得该状态，立即停止该行。它不删除候选、不改变最终值。相同四根节点降为327,304，减少59.11%，
分类与2,185个偏离选择完全一致。最终32768预算已经足够闭合全量，单搜索最大17,465。

35/35根、105/105规则实例完整，预算、TT容量、Fast、Hard、动作生成、restore与热分配失败全为0。

`TURN_LEFT` 1,232、`TURN_RIGHT` 48、`FIRE` 377。

## 为什么仍不能ACTIVE

8个candidate证书的首动作全部是`TURN_RIGHT`，历史结果全部为`EQUAL`且都是`V1_WIN_TO_V1_WIN`。
决定证书的最高不同维度为：反击安全2、敌方机动压缩2、接触距离3、资源1。terminal、committed safety、
已结算攻击、射线控制均为0。也就是说，单次响应偏离确实修复了“固定后续策略”缺口，但当前8个证书
只是局部位置价值，不是开火、命中或击毁证书。

而且证书价值依赖后续偏离策略。只覆盖candidate首动作、下一帧重新交给原控制器，会执行一个与证明
不同的policy，不能称为因果验证。

## 决策

保留单次偏离状态、固定TT和精确行剪枝，但拒绝接入production或直接做首步ACTIVE。下一步BP143只在
这8根上运行安全攻击事件证明：candidate必须在完整敌方/Chance支持下保证产生可自逃的威胁FIRE或
目标必死FIRE，并导出可执行continuation policy；否则这8根继续只作位置诊断。
