# BP350：导航变化后的攻击与资源时序审计

## 结论

本轮重建BP349全部125个决定性翻转对：57个胜→负、68个负→胜，两臂共250次确定性执行。双方动作流、参数、终局、帧数及事件计数全部复现。没有新候选、没有新干预，没有修改生产。

**导航到接敌的交接质量仍未建模；更短星路或更早接敌不是足够的战斗收益。** 这是下一步应验证的结构假设，不是已经证明的失败根因。当前数据不支持继续提高路线分、直接提高FIRE分，或削弱Risk门。

## 分母与方法

输入固定为BP349的768局紧凑记录。只选择胜负完全反转的125对，不包含平局转换及结果不变局。因此以下分组统计不能替代BP349的全体处理效应或显著性检验。

重建沿用冻结的CURRENT及NAVIGATION_FAMILY包装器。逐项断言双方动作流、稀疏参数、结果、终局类别、帧数、事件计数一致；保存每轨迹统计及32个哈希抽样的首分歧根，不保存逐帧replay。选16个退化、16个改善根；没有按根内容挑选。

首次“几何接触”定义为模型中距离≤9或有清晰射线，不是模拟器可见性ground truth。FIRE eligible仅表示当前候选Hard允许、Risk接受且未被支配，不表示开火有收益或存在可证击杀。动作数按决策根统计。

| LEFT→RIGHT | 47 | 54 |

没有首分歧直接把STUN或FIRE替换为导航。BP348的所有权隔离确实保留；但路线变化会改变后续资源使用和战术局面。首分歧不是“这一动作单独导致最终输赢”的反事实证明。

## 战斗行为的分化

| 指标 | 退化组原版→候选 | 改善组原版→候选 |
| --- | ---: | ---: |
| 决策根总数 | 4765→4824 | 6151→5654 |
| 几何接触根数 | 3692→3908 | 4791→4677 |
| FIRE次数 | 333→286 | 372→413 |
| 接触时可接受FIRE未选次数 | 1548→1610 | 2045→1975 |
| 接触时转向次数 | 2050→2112 | 2650→2565 |
| STUN次数 | 228→202 | 287→238 |
| 几何接触外STUN次数 | 62→25 | 76→31 |
| 有search proposal的根数 | 2074→2121 | 2617→2683 |

退化组更早进入接触，却FIRE减少、接触转向增加；改善组则FIRE增加。这为“接敌姿态/攻击准备”提供排查方向，但两组按结果筛选且时长不同，不能据此证明多开火会获胜。

双方组均明显减少远处STUN，所以“远处STUN减少”也不能单独解释退化。应查相同输入下技能是否确实改变可行攻击，不恢复一个全局远距技能奖励。

FIRE未选统计也包含无射线、低收益、冷却/模型支持等尚未逐项证明的局面。不能把这些次数称作漏杀数量。模型中immediate/horizon/unknown非零同样不能直接称作反击死亡。

## 终局：避免把空集合一律当作Risk故障

候选57个退化局终局为37单方被击毁、19星数负、1同归于尽星数负。

| 类别 | 局数 | 最后根可接受集为空 | 最后根Hard允许集为空 |
| --- | ---: | ---: | ---: |
| 单方被击毁 | 37 | 26 | 6 |
| 128帧星数负 | 19 | 19 | 19 |
| 同归于尽星数负 | 1 | 1 | 0 |

聚合的46个末根可接受集为空中包含19个星数终局，此时所有动作均无法扭转终局的可能性不能忽略；不能直接把46个都标成“风险门误删逃生动作”。

37个单方被击毁局中，30个末根选中行动的immediate质量>0，仅1个committed质量>0。这个组合提示应重点区分同帧未来开火、碰撞、支持不足及风险排序，但没有同根完整反事实证书，尚不能判定Hard漏证或可避免死亡。剩余11个仍有可接受动作的死亡局也不能因实际死亡就倒推风险模型错误。

## 下一步的可验证问题

不要继续围绕星路做更多启发式。先将导航与战术交接拆成三类证据：

1. **接敌姿态**：分别冻结两条轨迹的首次接触输入，在各自同一个输入下比较可选行动的朝向、合法进攻行动和退路；两臂的接触根已经不同，不能冒充共同输入。只有支持完整才判断存在姿态支配，不把近距离本身计收益。
2. **攻击所有权**：从接触时FIRE可接受但未选的根里分离无目的射击、需要瞄准准备、可验证压缩对手后继、已可直接攻击。先证明被错过的攻击质量，再考虑改选择器。
3. **死亡前安全**：37个单方被击毁的末段单独做同根反事实，区分无可活动作、未知支持和存在完整安全替代。终局星数必输与逃生失败分开统计。

可以先对32个已保存首分歧根关联对应轨迹做定点证据采集，不新跑胜率筛选、不提高深度、不添加朝向特例。若姿态与攻击质量不能区分正负样本，则应拒绝该假设，而不是继续调导航权重。
