- R29：1211 胜 / 1022 负 / 253 平，得分率 53.8013%；相对基线 +2.4135 个百分点，描述性 95% 区间 [+0.302, +4.479]。相对上批 R15 净局分 -24.5，百分点区间 [-2.946, +1.038]。

区间按实际地图分组进行 2000 次配对 bootstrap，没有多重比较校正。全部来自已知历史场景，全量包含开发和验证地图，不是新盲测或官方平台胜率。只校准炸弹 phase 的本地模拟器仍存在其他语义差异。过门结果是诊断候选资格，生产采用需另行移植与等价验证。

## 高效执行与等价性

- 开发 64 个地图沿用 BP388；新验证 128 个实际地图排除开发以及 BP388、BP389 验证地图，交集均为 0。
- noop 128 局逐动作、终局、计数与 BP386 一致；reference-half 128 局与 BP389 R15 一致，搜索节点及预算叶也一致。这两组不是候选轮次，不计策略收益。

- 全量复用本轮开发/验证的 384 行，逐行验证完全一致；复用次数单独记账。阶段压缩结果和元数据原子写入，完整产物不可覆盖。
