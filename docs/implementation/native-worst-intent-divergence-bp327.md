# BP327：正反首次分歧审计

## 范围与验证

复用BP317、BP323、BP326已有压缩数据，不运行新对战，不修改production。覆盖7个胜转负、4个负转胜，并纳入1个胜转平作为完整对账，共12个结果翻转。

每个样本校验：候选动作首次分歧索引等于记录frame、双方此前动作流相同、分歧处两个动作对应正确、BP326首分歧的全部候选行与BP323当前基线同根数据完全相同。因而不是拿不同轨迹上的同一帧号强行比较。

## 结果

| 首次分歧特征 | 胜转负7局 | 负转胜4局 | 胜转平1局 |
| --- | ---: | ---: | ---: |
| 取消FIRE | 0 | 2 | 0 |
| 取消STUN | 1 | 0 | 0 |
| 替代动作被其他动作原始worst/expected支配 | 4 | 0 | 0 |
| 替代动作存在预算截断 | 7 | 4 | 1 |
| 替代动作存在深度叶估值 | 7 | 4 | 1 |

“原始价值支配”不是Risk domination，也不包含intent维度。不能据此声称违反生产Risk合同。DEPTH_LEAF是正常启发式叶，并非自动等于bug；BUDGET标记也不能证明整个root没有完成任何搜索层。

### 1. 不能按全局开火量直接归因

7个胜转负中6个首次分歧是移动/朝向，另1个是STUN→RIGHT。两个FIRE→GO首分歧均落在负转胜组。全局FIRE下降可能是路线和接触时机变化的后果，不能把“保护所有开火动作”作为修复规则。这也不证明取消这两次FIRE本身导致胜利：后续策略同时变化。

### 2. 保留150分不等于保留原来的影响强度

CM：GO原始worst/expected为619/1395，RIGHT为537/725；RIGHT的intent150使首键变为687，超过GO619。原来的混合分比较为871对748，仍选GO。

Dq：STUN原始两项均胜过RIGHT，RIGHT加入150后改变选择。JjG seat1同样如此。Gw的RIGHT则被第三个GO原始两项支配。

因此BP326虽然没有改常数，改变比较坐标仍改变了intent的实际作用。这是选择合同的语义变化，不是“相同加分保证原战略力度”。四个样本只提供待验证的共同机制，不证明新增Pareto过滤就能恢复四局。

### 3. 最坏值改善幅度、截断标签均不足以分类

7j82 seat0退化根与GPI seat0改善根的原始worst改善恰好都是16；仅按改善阈值无法区分。两组全部都有BUDGET和DEPTH_LEAF，按截断一刀切会同时去掉正反效果。原动作带POLICY_REJECT_LEAF既出现在ESLY退化也出现在LXC改善。

### 4. 现有数据不能回答的部分

根行只存价值、动作、intent和exactBlock，没有攻击purpose、自逃证书、每个敌方响应的物理状态。不能把某次转向称为“已验证攻击准备被破坏”，也不能从某条最差数值推断真实必死。

## 下一步：先验证单步因果，不构造新策略

对本轮12个翻转首根进行一次局部干预：前缀及后续均使用当前默认，只在已核对的首分歧帧执行BP326替代动作。与已冻结当前完整对局和BP326整局对照。

- 若单步干预就复现退化，优先检查该根比较/价值来源。
- 若单步无退化但BP326整局退化，说明首次动作不能独立解释，需要定位后续连续覆盖及Plan/intent状态演化。
- 若负转胜只在完整BP326策略下出现，不能把该首动作抽成局部修复。

前置校验包括最终门实际接受替代、intent正确提交、双方共同前缀一致；若任一失败，该样本不得归因。只做诊断，不启用新生产规则、不调参数、不扩大到全量对战。之后才决定是否补充具体攻击证据或设计有限覆盖规则。
