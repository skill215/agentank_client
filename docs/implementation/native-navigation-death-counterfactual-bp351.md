# BP351：37个单方死亡退化局的末根反事实

## 结论

发现两类需要分开验证的结构问题，而不是一个通用“逃生不足”：

1. **终局收益与自身死亡风险可能不一致**：7局末帧改FIRE能同归于尽，按星数得到6胜1平；原策略却选择转向并单方死亡。
2. **风险向量与实际敌方响应存在错序样本**：6局存在躲过原死亡时刻的动作，4局动作已被Risk接受但被支配筛选删除，2局被阈值排除。其中3局最终转胜，另3局仍负。

这不是允许直接放宽Risk或取消支配：实验只覆盖实际V1响应，不是全部敌方动作或隐藏世界。下一步应首先核对终局效用语义，然后检查风险向量为何给这些行动更差的质量值。

## 协议与覆盖

固定BP350识别的37个“原版胜、导航候选单方被击毁负”局。重建37次原候选轨迹；每个最后决策根对所有不同的已生成Hard允许行动做一次强制替换，保留FinalActionGate，其后双方继续原策略。

总计174次执行=37次重建+137个分支。没有新场景，没有新候选，没有胜率资格测试。只有stun技能，不涉及teleport参数分支；NONE若被生成且Hard允许，也进入枚举。

校验：原轨迹双方动作、参数、结果、事件计数一致；分支在干预前双方动作及参数前缀一致；干预帧敌方动作一致；被强制行动确实发出；同动作干预保持原动作流和事件计数。137个分支均通过最终门，没有被门阻止的分支。

这里“躲过原死亡时刻”表示分支继续到更后帧，或对局已结束且自身未被击毁。它不等于长期安全，更不等于必胜。自己的死亡但同归于尽获胜只算结果恢复，不算逃生。

## 37局的互斥分类

| 类别 | 局数 | 含义 |
| --- | ---: | --- |
| 存在转胜/平行动 | 10 | 最佳实际分支9胜1平，其中7局同归于尽、3局逃生后转胜 |
| 仅躲过原死亡时刻 | 3 | 最后仍负，包括后续死亡或128帧星数负 |
| 所测试行动均未改善且未逃过原时刻 | 18 | 仅限已生成、Hard允许的单步行动集合 |
| 没有可测试Hard允许行动 | 6 | 无反事实覆盖；不能据此证明无物理解或Hard正确 |

10局结果恢复与6局延迟/避免自身死亡有3局重叠。不得相加成16局。

这些是知道对手实际行动后的局部oracle见证，不是可部署的选择策略，不能把9胜1平直接加回BP349胜率。

所有这7个FIRE行动Hard允许，但Risk不接受；immediate=5000，horizon=9375，committed=0，unknown=0。保存的首32个样本中，原转向与FIRE的immediate相同，转向horizon较低，FIRE的expected/tactical为10000但robust更低。

这给出非常具体的待验问题：Safety统计的是“自身会死亡”，还是“平台终局会输”？当死亡与获胜同属一个联合事件时，是否仍把它按输局风险扣分？同时，tactical=10000是否经过完整终局证明，还是仅启发式？二者都需要查证，不能拿10000直接当ForcedWin。

本轮没有验证敌方所有合法响应，因此这些FIRE不能直接升级成严格胜利证书，也不应加“领先就对枪”的特例。

没有一个存活见证同时满足“Risk接受且未被支配”。但这不证明Pareto实现算错：例如EYdW中GO的immediate/horizon为1428/4456，原LEFT为714/3742；支配过滤符合当前风险向量排序，只是实际V1响应下GO活、LEFT死。

因此应查风险向量的敌方动作支持、权重、量词及终局归类，而不是先删除Pareto。当前观测可能是风险模型失真，也可能是某次低概率不利响应实际发生；需要完整同根响应表才能分辨。

## 建议下一步

优先审计7个对枪终局根，建立联合结果表：自身死亡、对手死亡、星差、平台胜/负/平、Safety死亡质量、Risk失败质量、搜索终局值。对全部合法敌方响应与必要chance逐项对账，再决定是否存在“死亡≠失败”的语义缺陷。这个检查比继续加导航或开火奖励更直接。

随后对6个逃生见证建立同根响应矩阵；核对支配是输入向量失真还是合法风险取舍。6个Hard空集及18个无单步见证局继续标为未证明，若往前追溯，需要单独规定窗口和量词，不能称已经无路可逃。
