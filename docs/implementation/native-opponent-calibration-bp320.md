# BP320：敌方根动作分布校准审计

## 范围

固定16个已用开发场景，32局修复版重放，双方stun。每个实际执行prepare且返回成功的根，在搜索后恢复的真实根状态上读取敌方allowed mask与opponentWeight；以同一frame的敌方发出命令为标签。标签不是stun后实际位移方向。

本轮2,179根。该分母属于修复版ACTIVE轨迹，不与旧轨迹BP316的2,328根混用。所有根逐帧对齐，要求同帧恰好一个敌方命令；双方完整动作流和胜负均与BP317一致。没有训练、调参或更新production。

## 覆盖问题

实际动作2,154次位于搜索域内；25次（1.15%）已在engine候选中生成，但被root mask排除：FIRE10次、炸弹13次、stun2次。不存在完全未生成的实际动作，空域0。

源码rootEnemyActionAllowed明确无条件排除NONE/THROW_BOMB，对FIRE和stun使用资格启发过滤。因此这些事件不能仅用概率再校准解决。它们说明候选响应域不是完整实际行为支持，并不自动证明25次都造成输局或物理Hard错误。

完整分布对这些标签概率为0，故无条件NLL为无穷；不能加一个未说明的epsilon掩盖漏支持。本报告NLL单独标明只在覆盖的2,154根上计算。

## 权重校准

将当前权重归一化，对比同一allowed域内的均匀分布。比较指标越低越好：

| 指标 | 当前权重 | 同域均匀 |
| --- | ---: | ---: |
| 全根多分类Brier | 0.74132 | 0.70752 |
| 覆盖内NLL | 1.35388 | 1.22671 |

按整局分组，23局当前Brier更差，9局更好。不能因此声称均匀策略整局胜率更高——这里只比较预测质量。

| --- | ---: | ---: | ---: |
| 50%–60% | 491 | 54.22% | 33.81% |

低概率区也存在低估，不是将所有GO权重乘一个固定小数就已证明正确。根之间高度相关、场景重复使用，未计算独立Holdout显著性。

## 判断和后续顺序

BP318/BP319的两个失败不是单独的“碰巧猜错”证据：整批预测也显示GO高置信偏差。但当前不能将全部退化都归因于OpponentModel。

1. **支持合同优先**：区分物理不合法动作和因战术资格被剪掉但实际会执行的动作。后者必须体现残余支持/不完整，不得当成不存在。先做同根影子接线与UT，不立刻全放开所有分支导致预算爆炸。
2. **权重独立对照**：保持归约、动作域和预算，预注册当前权重与同域均匀的影子A/B；记录价值和最终选择变化。均匀只是诊断控制，不自动上线。
3. **选择权独立对照**：将最坏值和期望值保留分开，验证“预测优势”取得动作所有权的条件；不要一边改概率一边改门，避免无法归因。
4. 只有根证据通过才做小型ACTIVE，对两个已知退化和原胜局同时计转移；之后再使用独立场景，不反复针对本集拟合。

不建议此时继续增深搜索、恢复哨兵、全局禁用FIRE或拍脑袋降低期望系数。
