抽样在出结果前固定：按 sha256(bp392-equivalence-v1:id) 排序选 192 个实际地图；压力集合分别按 sha256(bp392-rotate90-v1:id)、sha256(bp392-mirror-x-v1:id)、sha256(bp392-star-early-v1:id) 选 64 个实际地图，压力集合之间原地图哈希不重叠。星星集合只取存在 frame>1 星事件的场景。后续星帧改为 max(1,floor(frame/2))，第 0 帧保持不变。几何变换同步更新地图、出生位置、朝向和全部星位置。更新场景身份和指纹；宿主按新指纹派生新种子，故是变换场景加固定新种子的压力测试，不声称几何对称等价。原始策略及候选在同一新指纹 / 种子上成对比较。

R41/R42 要求逐动作、参数、终局、帧数、计数和搜索工作量完全相同。R43/R44 要求逐动作、参数、终局、帧数、计数完全相同；VM 宿主不暴露真实搜索计数，其 summary 的常量 restore/hotAllocation 字段不能当作实测，报告标记 unavailable。原生移植及压力实验采集真实 restore、hotAllocation、搜索节点。

压力候选通过条件：净局分至少 +2，单方死亡负局和换位双负均不增加，节点不超过同集合原始策略 2 倍，双方错误/超时及原生 restore/hotAllocation 为 0。每个条件独立报告；拒绝实验仍计有效轮次。样本小且来自已知历史地图的变换，只提供压力证据，不自动采用生产、不外推线上胜率。等价性失败属于移植故障，保留证据，修复后重跑，不伪报成候选负结果。
