# BP394：R61–R70 五组新种子复核预注册

沿用 BP393 的 192 个不同父地图，仅使用原始几何、出生点和星事件。不改 R15/R29 系数，逐字节复用 BP392 的独立模块。生产树、Hard、安全门、节点预算、V1 时钟、炸弹 phase 适配器固定；不提交推送、不调用官方接口、不启用子 agent。

| 轮次 | 候选 | 环境 |
|---|---|---|
| R61 / R62 | R15 / R29 | 新种子组 01 |
| R63 / R64 | R15 / R29 | 新种子组 02 |
| R65 / R66 | R15 / R29 | 新种子组 03 |
| R67 / R68 | R15 / R29 | 新种子组 04 |
| R69 / R70 | R15 / R29 | 新种子组 05 |

每轮 192 地图 × 双座 = 384 局。种子为 sha256("bp394-seed-NN-v1:" + parentFingerprint) 前 8 位转 uint32，NN=01..05。冻结前检查每个父地图的五种子彼此不同且不等于 BP393 已观测的原种子、BP392 种子和独立复核种子。所有五组均执行，不因中途正负结果停选；不把新种子组合称为新历史盲测。

每组原始策略基准只执行一次，供两候选配对。五组共 5760 局。预检按 sha256(bp394-preflight-v1:parentId) 取 8 父地图，原场景原种子和 BP393 seed-replica 各双座，baseline/R15/R29 共 96 局，要求逐动作、参数、终局、计数和工作量与旧缓存一致。预检不计候选轮次。实际新执行 5856 局，旧缓存引用另计。

单轮压力门不变：净局分 ≥2，单方死亡负局和换位双负不增加，节点 ≤2 倍；双方 error/timeout、原生 restore/hotAllocation 均为 0。

本批五种子汇总预先规定：每候选 1920 局，按父地图整组保留 5 种子 × 双座 10 局相关性，固定 PRNG 初值 394 进行 2000 次配对 bootstrap。仅当净局分 >0、描述性 95% 区间下界 >0、累计单方死亡及双负不增加、每种子节点 ≤2 倍、至少 4/5 轮通过单轮压力门时标记 MULTI_SEED_SUPPORT，否则 INSUFFICIENT_MULTI_SEED_SUPPORT。该标签仍是本地种子稳健性证据，不自动采用生产；两候选并行比较不做多重比较校正。

同时报告五种子的最差收益与分组失败原因；R15/R29 直接配对比较，不能将很小差异当作可靠排名。旧三种子只作为独立列示的历史参照，不混入本批预注册晋级依据。

逐局记录真实生效种子及紧凑根轨迹。在同一父地图/座位上统计候选新增的单方死亡负局（候选死负、原始策略非死负）；至少 3/5 新种子出现才列为重复退化案例，保留首次动作分歧及终局信息。此为错误分析，不是强制动作反事实或普遍因果结论，不放宽 Hard。

每阶段独立进程；逐局带 SHA-256 检查点；冻结代码、输入及候选模块；完整产物不可覆盖。执行错误不计有效轮次，修复后重跑受影响阶段。已知模拟器剩余偏差和历史地图重复使用的限制沿用 BP393。
