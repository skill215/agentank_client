# BP32–BP33: 渐进深度与TT预算消融

## 结论

2/4/6帧渐进搜索不能靠浅层结论安全提前停止。固定16场景的774个根中，2帧严格闭合仅3个，4帧没有新增严格闭合；2帧与6帧完整向量一致仅12个。严格停止理论上只节省48个节点，远不足以形成性能跃迁。

TT命中是否占用“展开节点”预算也不是实际瓶颈。免计TT命中使节点计数从466,395降至150,905，但物理转移仍为535,138，完整对仍为293，预算耗尽仍为386，候选总耗时反而增加约3%。实验开关已撤回。

## 架构判断

当前6帧搜索的主约束是 `applyFrame` 物理转移数量，而不是逻辑节点计数，也不是浅层深度调度。下一阶段应测量并压缩严格等价的敌方动作/Chance后继，或复用已计算的后继转移；不得删掉量词、降低深度后把近似结果伪装成完整证明。

BP32诊断器保留为Shadow标定工具，不接管动作。BP33运行时代码已撤回，只保留不可变A/B证据。
