# BP389：第二批10轮排序实验预注册

2026-10-03。继承 [高效调优协议 V1](efficient-tuning-protocol.md) 的身份检查、单因素、错误零容忍及晋级门。BP386生产基线与128节点特化搜索不变，使用实例内诊断包装，不写生产或vendor源码，不调用官方接口，不提交推送，不开子agent。

开发集沿用BP388的64个地图/128局。验证集重新按 sha256(bp389-validation-v1:id) 排序选128个地图/256局，排除BP388开发和验证的所有地图。它是开发隔离集，不称新盲测。过门才执行冻结1243场景/2486局全量。

门槛不变：开发净局分≥2，验证与全量净局分>0；单方死亡和换位双负不增加；节点≤同集基线2倍；error/timeout/restore均0。结果出炉后不改门槛，不组合候选。

准备阶段重放BP388反事实有改善的14局，仅在对应根读取响应矩阵和intent加分；断言动作、终局、计数与BP386一致。只分析实际搜索成员；缺失/过期矩阵标为不可用。矩阵单元包含完整子树评分，不能把根状态的叶值当作该单元的分项贡献。

| 轮次 | 唯一变量 | 假设 |
|---|---|---|
| R11 | 期望混合系数设为0，仅最坏响应 | 期望混合掩盖不利响应 |
| R12 | 当前期望混合系数×0.5 | 小幅更保守能改善排序 |
| R13 | 当前期望混合系数×2，上限50% | 过度悲观压制有效进攻 |
| R14 | 对手动作权重统一为1 | 历史频率可能估计失准；保留混合系数 |
| R15 | 路径transition奖励×0.5 | 动作奖励可能压过到达状态价值 |
| R16 | 路径transition奖励设为0 | 测量路径奖励的独立贡献 |
| R17 | 最终选行动作的intent加分设为0 | 加分可能掩盖搜索差异；不改成员资格和commit |
| R18 | 叶值attack分项×0.5 | 进攻估计尺度可能过强 |
| R19 | 叶值projectile/bomb-pressure分项×2 | 已有投射物及炸弹压力可能被低估 |
| R20 | 模拟帧≥96且落后时，叶值star-route分项×2 | 终局追星紧迫性不足 |

叶值实验全部在分项合成后保留原总值±25000截断；terminal击毁胜负常量、Hard、Risk、动作域、搜索预算、对手V1及其他分项不变。路径实验同时覆盖scoreTransition与scoreAppliedTransition（后者在当前特化配置为零），保持两种路径记分的一致性。

每轮记录开发、验证、全量的逐局转移和调用命中；无行为变化不算收益。所有过门结果只标记诊断候选资格，生产采用仍需独立移植与等价验证。
