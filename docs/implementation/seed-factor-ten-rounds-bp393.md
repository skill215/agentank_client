合并三个互不重叠的父地图集合，以下为描述性点估计（每格 384 局）：

- R15：O0 +26.5，O1 -1，T0 +28，T1 -5 局分；种子差 -27.5，场景差 +1.5，交互差 -5.5。
- R29：O0 +34，O1 -4，T0 +26，T1 -1 局分；种子差 -38，场景差 -8，交互差 +11。

补充事后汇总：仅对原始场景，合并原种子、BP392 种子和另一组固定种子。每个候选 192 个父地图 × 3 种子 × 双座 = 1152 局；重采样以父地图为整组保留六局相关性，不改任何轮次的通过/拒绝结论。

- R15：净局分 +44；得分率差 +3.819 个百分点，描述性 95% 区间 [+0.564, +6.901]；死亡负局 336→314，双负 115→92。汇总不抵消单组退化。
- R29：净局分 +42.5；得分率差 +3.689 个百分点，描述性 95% 区间 [+0.781, +6.597]；死亡负局 336→320，双负 115→101。汇总不抵消单组退化。

交互差 = T1−T0−O1+O0；种子差 + 场景差 + 交互差 = T1−O0。此处是固定样本上的收益差分分解，不是“退化中某因素占百分之几”的因果结论。同一初始种子不保证不同动作轨迹后随机调用仍逐次对齐。

- 18 个阶段，累计阶段执行 708.6 秒。新执行 3648 局；四格对照另引用 2304 行旧缓存，未计为新实验。

- 核心回归 **483/483** 通过；全部对局 error/timeout/restore/hotAllocation 为 0；每局请求种子和实际构造器种子均匹配。
- 新场景指纹包含真实场景及显式种子，旧宿主和生产源码不改动。候选模块逐字节复用 BP392；V1 时钟和炸弹 phase 适配器身份不变。
- 每阶段独立进程，逐局检查点与冻结文件都有 SHA-256 校验；完整产物不可覆盖。
- 本地索引哈希与 BP392 相同，无新增历史地图证据。本批不是新历史盲测，也不外推官方胜率；模拟器其余语义差异仍然存在。

复现/恢复入口：`node tools/agentank/diagnostics/seed-factor-campaign.js <输出目录>`，每次推进一阶段；完成后运行 `seed-factor-report.js` 校验与生成机器可读分析。
