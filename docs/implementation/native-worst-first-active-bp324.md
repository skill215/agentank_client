固定16开发场景、双座位、双方stun。用BP323的同一根排序合同实际控制实验坦克；仅在本地包装器中运行，不修改production。搜索/响应域/深度/预算/概率均保持，最坏和期望都相同时才比较原含intent的值。仍通过原FinalGate。

## 成对转换

- 胜→负4，胜→平2。
- 负→胜1，负→平1。
- 胜保持14，负保持10。
- 正向得分转换+1.5，反向-5，净-3.5局当量。

两座位都退化的JjG从双击毁胜变为双被击毁负；CMkg座位0从击毁胜变为被击毁负；ESLY与Flz座位0从击毁胜变同星平。具体matchId、终局、帧数和星数全部保存在overview.matchChanges，不只报告总得分。

## 两个原目标没有在整局恢复

I52仍负，但从65帧被击毁变成128帧星负（0:2）；2oo仍128帧星负（0:1）。

这不反驳BP318的同根单步因果结果：全局使用最坏优先会在更早时刻改选，不能假设后面仍抵达原来的根。BP324在2oo第39帧的局面已经不同，提案为右转而非原来的FIRE/GO之争。I52没有同帧同条件owner根可直接对齐。

## 决定

标记NEGATIVE；不接production默认，不调阈值重跑同候选，不扩大当前实验到全量。

结论不是“应该恢复错误哨兵”或“越冒险越好”。它说明全局最坏优先把大量有用主动选择一并抑制，单看两个死亡根会产生局部优化错觉。

下一步从本轮丢失的主动胜局与BP318两种退化联合取证：检查最早同根分歧的攻击目的、最坏值支持质量和期望优势来源，区分可保留的主动攻击与证据不足的改选。先建立可检验的条件，不再全局切换保守/激进排序，也不直接调整一个风险常数。
