# BP336–BP337：远距离眩晕搜索入口与分层调度交互

## 结论

本轮发现的问题不是左右坐标计算不对称，而是搜索的使用范围：敌方眩晕会独立触发战术接触，即使双方相距23–24格且没有清晰射线。此时短期搜索可能以重复位置惩罚和追星意图的相互抵消来决定朝向，覆盖原导航。

仅取消这个远距离、无射线、敌方眩晕的搜索提案入口，在固定16场景32局开发集上改善了当前搜索和分层128两种候选。分层128改善更大，但这些场景已多次用于开发，不能认定独立显著性或全局75%胜率。生产默认未修改。

## BP336：早期转向归因

重建BP334的9个第2帧LEFT→RIGHT首分歧根，保持原CURRENT动作流与整局结果完全一致。展开216个叶状态、54对同敌方结果的左右转叶值：

- 216个叶状态水平镜像后，原始叶值及六个分量差异为0。
- 54对LEFT/RIGHT的原始叶值六分量相同，攻击分量均为0。
- 九个根均被标为TACTICAL_CONTACT，距离23–24，无清晰射线，敌方眩晕截止帧为8。
- 上一动作均为STUN，不存在上一动作反向转弯惩罚。
- LEFT路径分为-22；RIGHT为-142，其中120来自重复pose的superko惩罚（距离2的240经上下文epoch变化减半）。
- RIGHT同时获得150追星意图加分，LEFT没有；完整深度1因此使RIGHT净领先30。
- 当前近似深层值把RIGHT与LEFT的差距扩大到约159–167，150意图加分不足以反转，因而选LEFT。

这说明朝向差异来自路径历史与意图/搜索组合，不是镜像坐标错误。九局包含3改善、6退化；首次根的算分不能替代整局因果验证。
