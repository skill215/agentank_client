# BP347：路线评分的胜负翻转与所有权影响

## 结论

BP346并非仅修复后续绕障碍：路线奖励进入通用战术值后，在开局就重排朝向与技能的竞争。46个胜负翻转的首次动作分歧全部发生于第0–1帧，均由incumbent链路产生，而不是Minimax提案覆盖。

技能原始分数不变，不代表技能使用策略不变。18个案例原本STUN被新导航动作取代，改善与退化各9例。不能因此认定STUN必须优先；证据说明“目标路线进度”进入跨动作种类的通用总分后，产生了超出绕障碍范围的所有权改变。

## 重建范围与完整性

复用BP338 CURRENT和BP346候选的23个胜→负、23个负→胜，共46对、92条已有轨迹。没有新参数、新干预或新候选对战。

双方动作流、参数、事件计数与结果全部一致。首次分歧根的帧、位置、朝向、星位置和双方星数均相同；不声称内部策略历史也完全相同。只保存首次根、短后续位置和各自最后3个根，不保存整局replay。

## 通用分数的具体影响

HH6ho案例第1帧：

- 原LEFT expected=890，STUN=1530，最终STUN。
- 路线候选LEFT expected=2540，STUN仍1530，最终LEFT。
- 两行Hard/Risk都允许，策略portfolio两行都保留。

不是技能动作被删除，而是导航进度奖励改变跨类型排序。

1YfI案例第0帧：原LEFT/RIGHT/STUN均1530，稳定选择LEFT；路线后LEFT=-120、RIGHT=3180，STUN仍1530，选择RIGHT。这个改动发生在开局正常转向阶段，尚非原地绕障碍死循环。

因此“复用原1650权重”并不保证行为范围小：以前该奖励仅作用于GO位置变化，现在有效转向也可得到它，使技能与导航在同一标量上的相对尺度改变。

## 18个新增单方死亡的末根

18局中17个被模拟器粗分类为PROJECTILE_OR_COLLISION，1个为BOMB，不能再把前者武断细分为单纯子弹命中。

- 14局末根没有Risk可接受动作，但仍有Hard允许动作，进入风险回退范围。
- 1局末根所有记录候选都没有Hard允许动作，最终NONE；没有证明当时还有可救动作。
- 3局末根存在Risk可接受动作，其中选中动作也可接受。

14个回退末根的选中动作immediate fatal mass均5000、committed mass为0。这是已有软危险压力，不是committed必死证明。不能仅因最终死亡就判定Hard漏证，也不能因存在Hard允许动作就认定存在模型安全替代。

死亡帧从19到127，远晚于第0–1帧首次分歧。首根分析不能证明“单次不放STUN直接造成几十帧后的死亡”。需要区分开局策略变化、接战时机和末端风险回退问题，不把它们合成一个阈值问题。

## 下一步方向

停止把路线进度加到所有候选共用的战术标量。应拆开：

1. **导航内部质量**：GO/LEFT/RIGHT之间用可达距离、朝向进度识别绕路和有效转向。
2. **跨目的动作选择**：是否使用技能、开火、保命、导航，继续由其各自的资格与现有仲裁决定；路线距离不能直接冒充战斗收益。

下一诊断候选可在原选择已经属于导航动作时，验证同一Hard/Risk允许导航集合内的路线比较；首先要求技能/攻击原有所有权不会被单纯的路线加分挤掉。不能硬编码“STUN优先”或只对这些地图/帧开关。

这是一项新的所有权合同，需要UT验证后做独立ACTIVE比较，不能因为8个局部反例修复就认为整体架构正确。保留CURRENT生产默认，BP346候选不合入。
