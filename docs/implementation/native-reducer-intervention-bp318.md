# BP318：两局退化的单步因果验证

## 干预结果

两个首次分歧根；每根使用OLD/FIXED后续策略，各跑自然动作、强制旧动作、强制新动作，共12局。双方干预前动作前缀一致；强制自然动作与不干预的双方动作流完全一致。介入通过现有FinalGate并同步intent commit，没有绕过Hard。

| 根 | 第一步 | OLD后续 | FIXED后续 |
| --- | --- | --- | --- |
| I52 / seat0 / frame48 | GO | 128帧同星平 | 128帧同星平 |
| I52 / seat0 / frame48 | 右转 | 65帧被击毁负 | 65帧被击毁负 |
| 2oo / seat0 / frame39 | GO | 70帧击毁胜 | 70帧击毁胜 |
| 2oo / seat0 / frame39 | FIRE | 128帧星负 | 128帧星负 |

在这两种固定后续策略和固定对手/随机种子的实验中，第一步足以造成并恢复退化，不需要再假设后续修复版连续决策才是必要原因。不是对所有对手策略的必胜/必死证明。

## I52：收益分支上涨，最坏响应没改善

GO对敌方GO/左转/右转的值为10543/40/40，修复前后不变；rootScore1274，intent bonus150，最终比较值1424。

右转对敌方GO的值从12796升到20362；对两个转向的值仍为-103。其rootScore从1413升到2303，超过GO。权重16200/10000/11000，期望混合比例2700/10000。

Hard、Risk可接受性、死亡质量均未改变：GO和右转都Hard允许、acceptable=1、未来开火质量625。风险/几何排序并没有证明右转更安全。GO最坏40，右转最坏-103；是有利响应的上涨推动了选择逆转。

深度3、预算叶61、Fast不完整1。右转exactBlock=9（预算+深度截断），GO=11（另含Fast不完整）。这些值不是严格完整对局证明。

## 2oo：终局高值进入期望，压过更好的最坏响应

GO rootScore18033不变。FIRE对敌方GO的值从42354恢复到100000，其余响应7062/25000/25000不变。FIRE rootScore16731→31120，加150 intent后16881→31270，超过GO。

敌方GO权重41600，总权重53600（约77.6%）；期望混合3216/10000。FIRE最坏响应7062仍明显低于GO的15641。

两动作都Hard允许、acceptable=1，risk.dominated标志均为1。owner并没有把该标志作为统一排除条件；但GO和FIRE同处这个状态，所以不能将该标志直接解释成此次翻转的原因。owner最终比较search+intent值，proposal从GO切为FIRE。

深度3、预算叶63，候选exactBlock=9。根某cell达到100000不代表整行动严格强制胜，更不代表全根支持完整。需要下一步追踪该cell内部的终局来源、chance和后继动作覆盖，才能判断模型错误还是加权策略下注不合适。

## 当前判断与下一步

归约修复本身算对了；旧哨兵意外压低了高收益分支，相当于不受控的保守偏置。不能恢复数学错误作为解决办法。

已验证的直接机制是：有利分支高值→加权期望增加→不完整搜索值取得动作所有权→第一步改选→这两个固定续局退化。尚未证明应全局禁用期望、降低混合比例或提高风险门。

下一步先追踪I52右转/敌GO和2oo FIRE/敌GO两个收益分支，分离真实终局、启发饱和、预算叶和chance聚合的贡献；再用同根影子比较“最坏值/期望值分离仲裁”与当前混合。保持归约修复，不调阈值，不扩大对战，不据两个样本接入新默认策略。
