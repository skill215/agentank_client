## 物理非法与策略裁剪不能混同

当前rootEnemyActionAllowed排除NONE/炸弹属于显式策略选择。FIRE/stun资格条件也是战术判据，不是“不可能发出该命令”的证明。GO被地形或占位阻挡也可能是合法无效动作；除非证明其整帧后继与某保留响应等价，否则不能按物理不可能删除。

本轮没有任何新物理排除或等价证书，不伪造这类证书来缩小residual。25次遗漏事实只用于事后覆盖检查，不用于提前决定哪些动作应该保留。

## 最小合同

开发侧ResponseSupportLedger输出：generatedMask、searchedMask、residualMask、generatorComplete、complete。

- searched只指已在本次根响应域内；不等于搜索深度完整或物理后继完整。
- 所有未搜索的已生成列都保留residual；名义权重为0也不能抹除。
- 同动作的不同参数/代表列可能不同；一个被搜索代表不能自动消掉其它被剪代表。掩码只用于动作类别存在性，不能当作完整参数身份。
- 每根清零，不将上一根支持泄漏到当前根。
- 没有生成器完整证据或空域，不得输出complete。
- 不写Hard、Risk质量、score、Proof或最后动作；不把未知质量随意设成1%、100%等概率。

账本只用少量标量和位运算，update不新增对象/数组。尚未接production，也未做V8堆分配或性能标定，因此不声称整引擎零热分配已获得新验证。

## 避免新的全局退化

如果把residual存在直接变成“禁用该根/拒绝全部候选”，这批所有搜索根都会失效，重新掉入全面fallback。正确性标记与近似策略可用性必须分开：

1. 近似评分仍可作为策略建议，但明确受裁剪域和截断限制。
2. 严格证书不得由不完整响应域产生；区间层保留未知残余，不能以归一化消除它。
3. 需要决策证据时，再选择展开影响排序的残余，或证明其后继等价；不是立即展开所有列。

这里的第2条是拟议支持合同，不表示已经修改或验证了production所有Proof路径。

## 下一步

支持层信息现已可独立表达。先保持动作域、归约和预算不变，做当前nominal权重与同域均匀权重的影子A/B，检验预测偏差如何影响评分和最终选择。残余标记同步报告，不把均匀分布误当成完整分布。

之后再独立验证最坏/期望分离仲裁，避免把“补支持”“改概率”“改所有权”三个变化混在一轮。真正的物理排除、残余扩展和严格证书接线需要各自UT和oracle，不依赖两个退化样本的特例。
