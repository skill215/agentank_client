## 发现

24对中得分改善5对、退步5对、持平14对。新增死亡6对里只有2对得分下降，另外4对得分不变；这解释了只看胜率或得分会漏掉风险退步。

6对首次动作分歧前的回放前缀完全相同，证明权重变更在相同历史状态下确实改变了策略选择。所选动作都通过hard与final gate；其中2对候选动作的风险acceptable为0，而基线为1。5对候选所选动作的robustLower较低，2对horizonFatalMass较高。这些指标属于风险评估层，不能直接当搜索内部混合评分。

源码的blended使用 worst + trunc((trunc(sum/count)-worst)*weight/10000)。提高权重会降低最坏回应对分值的影响，但本批未捕获该搜索节点的worst/sum/count，不能用外层expected/robust数值替代它们，亦不能声称已经证明混合公式有错误。

## 决策

接受本批诊断流程产物；不恢复全局权重加倍，不增加新的安全规则，也不把历史回放记成泛化通过。候选机制仍缺单点干预证据。

下一批优先对opponent-5-shield帧62及opponent-6-stun帧33做一次动作替换：仅在该帧替换为基线动作，其余帧仍按加权候选运行。保持随机事件一致，测是否改变死亡与得分；随后在收益案例检验副作用，才考虑新的条件化机制。两个位置由全部新增死亡共同状态中的acceptable降级规则选出，属于发现集，不能充当独立确认集。
