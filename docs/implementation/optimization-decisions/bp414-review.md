## OPT-D-0002：同等逃生证据下比较退出步数

来源：BP412 定位逃生交接，BP413 证明第 104 帧已允许的 GO 可消除已知炸弹死亡。原策略的逃生证明、暴露、余量、分支数及前置风险字段打平后，robustLower 选择 LEFT。选择的候选仅替换这一级排序。

替代方案：继续参数搜索缺少机制依据；放宽硬门槛无法解释两个动作都已经允许的事实。因此先实现局部进展指标。其优势是范围小、可消融、可复用，风险是静态路线不考虑未来敌方动作和弹道。

实现使用诊断包装器，在正常策略提交前返回候选行。适用于单个已知炸弹、自身无活动效果、COMMITTED_ESCAPE、后继证明为 2、所有前置风险字段相同且动作获门槛允许的情况。只有更短且可在炸弹时间窗内完成的静态路径才替换原行；否则保持原选择。没有加入局面编号或坐标特判；第 104 帧起用是本次消融协议的实验控制，不是通用规则。
