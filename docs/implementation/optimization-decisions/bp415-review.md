# OPT-D-0003 / OPT-R-0003：新对局验证 BP415

日期：2026-10-08。按用户建议生成新对局，再将全部回放保存为可复用场景。

## 方案与执行

冻结 OPT-D-0002 候选代码，使用已有随机地图生成器生成 32 张 19×15 地图，双方换边，候选开/关配对，共 128 局。全部是本地模拟器新对局，不是平台实战；未使用旧对局后缀、指定帧动作或根据胜负筛选地图。

生成种子和随机 nonce、地图、初始坦克/星星位置、代码及模拟器身份均已记录。与审计范围内 24 个历史地图哈希比较无重复；此范围仅包括 native-causal-audit 下指定命名的场景文件，不声称覆盖所有历史平台地图。候选开/关共享按帧、事件、角色编码的随机数，双方技能固定 stun。

优点：直接产生候选设计时未见过的自然完整对局，易配对和复现。缺点：随机对称地图和固定对手/技能不代表平台总体；32 个地图只能做覆盖与大效应筛查。预设地图平均差的 Hoeffding 95% 区间半宽约 0.4802，无法精确确认 0.1 级别的小收益。
