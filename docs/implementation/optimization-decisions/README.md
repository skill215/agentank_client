# 算法调优决策流程 OPT-P-001

本目录记录研究者/Agent 对调优方向、代码改动、实验和采纳的决策，不记录 Minimax 的棋步选择。流程采用失败诊断、单机制消融、独立验证、运行环境验收四阶段。当前目标是提高每单位实验成本获得的可信结论，而非填满轮数。

## 编号和事实来源

- `OPT-P-001`：流程版本；改变准入规则、统计定义或评审节奏时登记新版本。
- `OPT-D-0001` 起：调优方案。一个可证伪假设对应一个编号；实质修改机制或验收标准需新编号，并用 parent 关联原方案。
- `BP414` 等：实际实验批次；沿用已有编号，不把游戏数、种子数当成方案数。
- `OPT-R-0001` 起：评审。可对同一方案追加多次评审，保留全部历史；汇总按方案取最新评审。

机器事实源是 `config/experiments/optimization-decisions/` 中的追加事件。事件含前序哈希，所有证据绑定路径和 SHA-256。工具拒绝重复编号、断链和证据漂移。此为本地可检测变更的记录，不宣称外部不可篡改。不可修改已登记证据；修订应另存新版本。中断留下 `.lock` 或 `.tmp` 时应核实进程并记录恢复，不能自动清除后重跑。

## 每个方案必须记录

注册记录包含日期、流程版本、类别（流程/算法）、前置方案、问题与机制假设、基线、适用边界、至少两个替代方案的收益/风险/选择理由、证伪条件、硬/软指标、阈值、独立单位、成本上限、证据和下一步。事后补录必须标为 retrospective，不能伪装预注册。

评审包含实验编号、逐项标准及 pass/fail/unknown、原始数据与摘要哈希、尝试/完成局数、独立单位数、执行时间、分析时间、指标数值与单位、效应与不确定性、原因、处置、局限和下一步。未知时间用 null，不填零；历史局面上 32 个随机种子属于一个局面，不能计 32 个独立地图。局部胜率、得分、死亡率分别报告。

候选触发率、行为差异、约束距离应在对应实验摘要中记录分子/分母和各维度单位。不同量纲不随意相加为单一惩罚分。未测指标标未知并说明原因；暂未触发不等于无收益。

## 执行和评审

1. 先定位失败层：实验基础设施/证据完整性、游戏机制、策略选择、适用数据不足。实验失败原因与局内死亡原因分别统计。
2. 基于已有证据选一个机制，写入注册记录，冻结基线、代码、数据和阈值；避免重复运行已有充分消融。
3. 使用现有 experiment-runner 执行；保留预算、哈希检查、无自动重试和每批评审约束。历史状态实现消融只算 measurement，不因有候选代码升级为独立优化验证。
4. 每批结束或最多十轮必须评审；完整性失败立即停止。总轮数是上限，不是必须完成的目标。
5. 处置：retain=保留继续验证；improve=新方案修订；reject=否决该假设；rollback=撤回已应用改动；defer=证据/资源不足；accept=满足注册的全部采纳标准。算法 accept 必须到 release 阶段；本地通过不是上线。
6. 算法独立验证应先完成数据来源审计和样本精度评估，预留确认预算；之后才进行目标环境成本验收。不得为凑批次重复包装旧样本。
7. 每十个已评审方案或一个阶段结束时评估流程：主要淘汰原因、证据缺口、单方案成本和未解决比例。只在证据支持时变更流程版本。现阶段不凭一个局部成功放宽安全门槛。

## 统计口径

| 指标 | 分子 / 分母 | 解释 |
|---|---|---|
| 阶段达成率 | 达成当前预设阶段标准的方案 / 当前阶段结果明确且数据有效的方案 | 局部机制可计入；必须标阶段 |
| 优化成功率 | 独立验证或更后阶段通过的算法方案 / 对应阶段结果明确且数据有效的算法方案 | 排除局部种子重复、流程变更和执行故障 |
| 接受率 | accept 的方案 / 已有评审的方案 | 保留、延期都不算接受；同时显示未解决数 |
| 可行率 | 所有硬标准通过的方案 / 所有硬标准均已判定的方案 | unknown 不当失败；单独显示覆盖度 |
| 失败原因 | 按最新评审 primaryCause 计数 | 可附次要原因，避免重复归因总和冒充方案总数 |

分母为零返回 null。按流程版本及流程/算法类别分组；历史覆盖不完整时仅报告已注册集合。精确实验组成本去重，但不同组可能重叠，不能直接相加。完整历史成功率需要另做历史迁移审计。

## 当前选择

`OPT-D-0001` 建立本流程和台账；`OPT-D-0002` 实施同等逃生证据下的静态退出步数候选。BP413 的发射层干预已经支持机制，BP414 检查候选进入正常策略提交后是否仍成立。静态路线忽略未来敌方移动和弹道，绝不是安全证明；候选只作允许动作之间的受限排序。

```sh

node tools/agentank/diagnostics/optimization-decision-ledger.js verify config/experiments/optimization-decisions
node tools/agentank/diagnostics/optimization-decision-ledger.js report config/experiments/optimization-decisions
```
