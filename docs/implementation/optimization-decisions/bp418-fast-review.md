## 唯一改动

上一轮在晚期 neutralBetter 比较器添加路线平分规则，没有改变动作。本轮检查发现，buildPortfolio 在更早的 baseBetter 中选出单个导航基准动作，可能使晚期规则失去比较机会。

本轮将规则放到 baseBetter：只在导航模式、自身无活动效果、动作合法可接受且风险与已有评分完全相同的情况下，以更短的静态争星路线替代默认行号排序。原始评分、安全门、风险字段和生产源码均未改动。实现仅通过诊断包装器接入实验。
