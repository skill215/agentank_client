# OPT-P-005 多目标快速优化流程规范

生效日期：2026-10-09。用户同意采用；约束研究者/Agent 的调优决策，不约束 Minimax 局内决策。继承 OPT-P-001 台账与证据规则、OPT-P-002 快速迭代原则，以本版规定后续候选筛选流程。已冻结的历史批次继续按原标准评审。

## 六步执行

1. 注册：明确一个主结果指标（默认胜=1、平=0.5、负=0），附死亡与成本约束；为每个机制写假说、反证条件和独立 OPT-D 编号，登记替代方案。硬门槛限合法性、完整性和明确运行上限；质量取舍提前写阈值，不要求所有指标同时最优。
2. 产生候选：默认最多三个不同机制，各自只改一个因素。第一性原理必须转成“什么改变、为何改变、怎样测出错误”的可检验假说。允许不同目标分别探索，Pareto 集合只用于保存线索。
3. 同条件快筛：同地图、座位、随机事件、对手和预算；先确认改动实际触发。历史场景只作发现/回归。固定样本与预算，不因结果不理想追加试验。
4. 选优：先满足预注册约束，再按主指标、死亡、成本排序；无合格者保留基线。候选成本低但死亡增加不能自动判优。次目标线索需新编号及新数据，不能改写原目标为成功。
5. 新数据复核：对选中候选使用未参与选择的新地图；按对手配置分别报告，交叉配置共享地图按地图聚类，不能把每局当独立地图。组合改动必须包含基线、A、B、A+B对照，不假定收益相加。复核通过后才考虑目标运行环境验收和生产采纳。
6. 关闭与改进：每批结束或最多十轮复核，明确 retain/improve/reject/rollback/defer/accept。完整性失败立即停止；预算是上限。每十个已评审方案或阶段结束汇总淘汰原因、复现率和单位成本，仅凭证据修订流程并创建新版本。

## 必须保存

OPT-P 流程版本、OPT-D 方案、OPT-R 评审、BP 批次；基线/候选/生成器代码哈希；数据来源与重叠范围；参数、随机种子、地图、座位、对手；原始结果与回放；触发和行为变化；胜平负、得分、死亡、计算工作量和已测耗时；各门槛距离；样本独立单位与局限；尝试/完成/失败数、预算消耗、处置理由和下一步。证据追加封存，未知值为 null，不把未知写成零。

报告分别列执行完成率、阶段合格率、新数据复现率、生产接受率，提供分子分母；流程与算法分开统计。总工作量、每次搜索工作量与平台耗时分开；短局或早死导致省计算不是加速证据。并行耗时不能相加成总墙钟时间。

## 方法选择

常规采用“多目标提出候选＋主目标约束选优＋新数据复核”。逐轮减半可在候选多时另行注册实验，必须固定晋级规则并记录误淘汰风险；贝叶斯搜索仅在可比历史数据和参数维度需要时采用。方法本身的优劣应在相同总预算、多批任务比较最终增益、复现率和成本，不能根据一次候选胜出宣布某种方法普遍最佳。

## 本版首批 BP422

继承 BP421 唯一合格候选：期望权重乘二，上限7000，不重新调参。8张全新地图，每张对同一 V3 策略的 stun/shield/teleport 三种技能配置，基线与候选配对，共48局（8个地图独立单位）。座位在地图间平衡，候选技能固定 stun。这是对手配置泛化测试，不是三个不同算法。

预先合格条件：24局总得分至少+2；总死亡最多+1；总转移次数≤基线120%；每种对手配置得分差≥-0.5、死亡差≤+1；所有完整性检查通过且候选触发。通过只保留运行环境验证，失败停止无条件推广；局部线索另行登记。48次尝试，不自动重试，不追加样本；每局10秒、每分支600秒，实验执行总预算1200秒。小样本仅用于快速决策，不宣称总体优势确定。
