# OPT-P-004 / BP421 方法比较与选择

日期：2026-10-09。登记 OPT-D-0013—0016，复核 OPT-R-0013—0016。48局完成，607项测试通过，1509个随机事件校验通过。生产算法未改动。

## 判断

预设多目标、快速筛选、分别推进、以机制假说指导实验，适合本项目探索。需要增加明确主目标、新数据复核、组合对照与固定停止条件；否则容易把历史偶然收益、非支配或低计算量误认为成功。第一性原理用于提出可证伪假说，最终以对局证据取舍。

本轮选提高期望权重为下一阶段唯一主候选；浅搜索和组合停止推进。本结论针对具体配置，不是证明单目标方法普遍优于多目标方法。

## 实际比较

12张新生成地图，每张四组，同座位同事件种子，共48局。地图与历史32张及本批彼此不重复，未按结果筛选。每种方法只提出一个冻结配置：M1按上轮得分选期望权重；M2保留Pareto低死亡线索选浅搜索；M3组合两种机制。共享发现数据、公平新样本复核。

|方案|胜/平/负|总得分|死亡|转移次数|相对基线工作量|处置|
|---|---|---:|---:|---:|---:|---|
|基线|6/0/6|6|4|155428|100%|生产保持|
|M1 期望权重|9/0/3|9|3|106620|68.6%|保留主候选|
|M2 浅搜索|5/1/6|5.5|5|93897|60.4%|停止：得分回退|
|M3 组合|6/0/6|6|6|76969|49.5%|停止：无得分增益且死亡增加|

固定合格条件：总得分至少+1，死亡最多+1，总转移次数不超过基线120%，完整性和机制触发通过。合格者按得分、死亡、转移次数依次排序，无合格则留基线。仅M1合格，候选合格率1/3；生产接受率0/3。流程完成率48/48。不要把流程执行成功与算法生产采纳混为一谈。

三个候选均Pareto非支配，但低成本不能抵消不符合本轮目标的质量损失。组合交互总得分为-2.5（组合−权重−浅搜索+基线），提示此次组合并非收益相加，仅为描述性结果。权重线每次搜索约190次转移，基线约197次；总工作量下降31.4%主要不能解释为内核加速，对局长度、搜索调用也在变化。

## 方法工具箱及优劣

|方法|优点|缺点|本项目处置|
|---|---|---|---|
|单主目标加约束|决策快，避免目标冲突|可能忽略未来有价值的折中|本轮具体候选胜出，用于最终选择|
|多目标/Pareto探索|保留不同机制线索|非支配集合可能很大，死亡更快也可能更省计算|保留作候选生成，本轮浅搜索线未复现收益|
|因子组合/消融|辨识单项与组合贡献|组合数随因素增加迅速增长|本轮2×2已验证，组合不采用|
|逐轮减半分配预算|差方案早停，更多预算给好方案|早期噪声可能误杀|尚未比较验证，下一批可预设4候选→2→1；每层同样本，晋级用新样本|
|失败场景定向搜索|机制清晰，发现问题快|易过拟合困难样本|作为发现工具；修复后仍需代表性新对局|
|贝叶斯/代理模型搜索|连续参数较多时减少昂贵试验|依赖可比历史数据，额外建模成本|暂不优先，未验证优于当前简流程|

建议采用组合流程：多目标产生少量互异候选→同预算快筛→主目标加约束选择→新地图复核→仅对有证据互补的机制做组合。每批先编号并冻结假说、预算、样本及退出规则；结束记录保留/修改/否决及原因。不为追求接受率放宽门槛，不持续扩样直到得到想要结果。

## 限制与下一步

12张地图、一个对手配置，样本胜率75%不能当成总体真实胜率。保守配对得分均值95%界半宽约0.784，无法证明小幅改善；它也不是多候选选择校正。工作量是转移次数代理，不是实际平台耗时。本轮没有生产采纳，也不能为整个优化方法作普遍排名。

下一阶段优先给权重线一次固定预算、覆盖不同对手的新数据复核；评估真实时间预算后再决定生产采纳。保留当前生产基线与全部失败证据。未来若比较优化流程本身，应在相同总预算、多批独立任务上比较最终增益/耗时、合格率与复现率，不能只比较一批挑出的一个配置。
