# BP338：分层128＋几何入口的开发集外验证

## 结论：NOT_QUALIFIED，不合入生产

BP337在16场景上的75%得分没有扩展到本批64场景。冻结组合候选的综合得分从CURRENT的50%下降到41.015625%，单方被击毁减少，但开火、击毁与星数竞争同时下降。

这不证明“取消远距离眩晕搜索”本身错误：本次比较包含分层调度和入口两项变化，尚未分离各自贡献。也不能以性能改善抵消行为质量退化。生产默认保持不变。

## 数据与执行合同

- 候选固定128物理转移、最多3完整层，远距离>9、无射线、敌方眩晕时不产生搜索提案。不调整任何评分或阈值。

## 退化集中在哪里

最明显的结果结构是：单方被击毁少9局，星数负却多24局；FIRE减少209次（26.29%），单方击毁少3局。组合候选没有把更多存活转为攻击或终局优势。

这只是两组整局终局分布，不能断言那9局被救活后逐一变成了24局星数负。因果归属还需要同场转换与缺失的两个实验臂。现有结果足以否决直接合入，但不足以把损失单独归给入口、浅层或导航。

搜索方面，CURRENT9282次搜索；候选9399次入口中929次跳过、8470次搜索，完成深度0/1/2/3分别334/5655/2423/58。不同轨迹的搜索次数和本地累计耗时不可当匹配输入性能资格。
