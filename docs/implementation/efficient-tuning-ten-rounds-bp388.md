## 已固化的协议

见 [高效调优实验协议 V1](efficient-tuning-protocol.md) 与 `tools/agentank/diagnostics/efficient-tuning-campaign.js`。协议和执行器均由manifest哈希绑定，实验前已冻结：开发集64个地图/128局，验证集128个不同地图/256局；双方换位，同地图不跨集。验证集未参与本次规则选择，但1243场景已有历史总体分析，不称全新盲测。

候选先要求开发集净得分至少+2局分，单方死亡/换位双负不增加；验证与全量要求净得分>0且同样满足安全护栏、节点不超过基线2倍。每轮单因素；未通过就停止，不事后放宽门槛。正收益也可能因死亡或双负增加而淘汰。

## 反事实给出的下一步依据

20局分层样本、60个根、233个实际执行的替换分支中，14局可改善；50个正向分支不能当成50场可恢复胜局。14局全部存在Risk已接受的改善动作，其中10局存在已纳入搜索的改善动作；22个改善分支的搜索值反而低于原选择。这些样本支持优先调查价值排序和对手响应估计，而不是先放宽Hard或扩大动作域。

候选动作覆盖GO、左右转、FIRE、THROW_BOMB和STUN，未发现可以直接概括成“总是多开火”或“总是抢星”的单一动作规则。下一轮宜在这些根上复用状态和已算出的响应矩阵，分别检查最坏响应、加权响应、路径项和叶值贡献，再形成有触发条件的单因素候选；继续保留胜局控制和地图隔离验证。

未恢复的6局仅表示本次三个指定帧窗口和合法替换未改善，不能推断整局不可恢复。样本每层仅4局，不能把14/20外推为全量可提升70%。
