## 排序根因取证与测量修复

前一批反事实中有改善的 14 局原轨迹重放完全一致；50 个正收益分支里，22 个分支的选择动作与改善动作均有实际搜索矩阵。其余矩阵缺失或不可用，不作归因。22 个可比较分支中，17 个改善动作的最坏值和期望值都更低，仅 1 个存在 intent 加分翻转排序。完整根响应值包含子树回传，不能直接当作根叶值分项；这些结果提示还需检查子树估值及响应建模，不能据此证明某个叶项就是根因。

首个预检尝试在任何候选轮次之前因 ROOT_MATRIX_RECONSTRUCTION_DRIFT 停止。已改为在实际 rootCell 调用时记录权重及值，重新计算每行混合值并断言与 rootScore 完全一致；修复后的 14 局预检通过。原失败目录保留，不计入十轮候选结果，未改生产、实验参数或样本。

运行在 R19 全量阶段收到终止信号，以退出码 143 结束，具体外部原因未确定。R11–R18 和 R19 开发/验证已完整落盘；中断时全量日志已到 384 局，但未形成完整逐局文件。这些未归档计算未计入本报告对局数。恢复入口仅增加不可变产物复用与身份校验，比赛 worker 逻辑与原始版本逐字一致；已有产物哈希全部保持，R19 全量从头重跑，再继续 R20。恢复校验另修正了 JSON 序列化省略 undefined 字段的比较方式，发生在任何新对局之前。详见 recovery.json。

## 高效流程与校验

- 沿用上一批 64 个开发地图；本批验证为另外 128 个地图，按实际地图内容哈希排除本批开发及上一批验证，重叠均为 0。验证集合不是首次看到的全新盲测集。
- 复用冻结基线，单因素候选依次过开发、验证、全量门；各阶段 4 个 worker 运行，候选之间不组合。
- 冻结场景、V1、确定性时钟、Node 版本、宿主、炸弹适配器及实验源码哈希；逐局产物与参数、调用命中、收益损失、节点工作量均留档。
- 完成 23 个阶段、15516 局；error / timeout / root restore failure 均为 0。Minimax 测试 **461/461** 通过。

## 下一步优先级

1. 优先将 R15（路径评分减半）作为独立移植与等价验证目标：全量增益 +84.5 分，单方死亡 688，节点 +0.45%；相较 R16，它保留部分路径评分，死亡更少，搜索工作量也更低。此处为后续工程优先级判断，不是已证明优于 R16。
2. R16 保留为对照。它比 R15 仅多 2.5 分（+0.101 个百分点），配对地图 bootstrap 的描述性区间为 [-2.093, +2.256] 个百分点，当前证据不足以分出高下。下一批先拆开火、GO 边缘、投弹软惩罚及转向子项，避免直接组合参数。
3. R19 保留为次级方向：虽过预注册门，但相对基线的描述性区间跨零；先做独立确认，不与路径候选合并宣称收益。
4. 已按实际地图去重，为每个合格候选保存 12 个最大回退地图和 12 个最大收益地图，含换位结果、终局、计数及首次不同动作的决策序号。这些是后验调试样本，不能充当新验证集。
