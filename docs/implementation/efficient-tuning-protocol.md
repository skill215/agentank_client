# 高效调优实验协议 V1

2026-10-03 固化。适用于 BP386 校准环境上的后续本地实验；用户要求完成10轮。

## 不变量

- 环境：固定 bomb-phase-adapter 身份；冻结 BP386 的1243场景、2486局、双方stun、128帧。
- V1使用相同确定性时钟和回合fallback；runtime-only原始winner不计分析输赢。
- 每轮开始前冻结假设、唯一变量、样本、门槛；结束记录分母、成本、正负转移、结论。
- 场景fingerprint、生产树、V1和对战主机身份必须吻合；双方error/timeout和V2 restore均为0。
- 保留dirty文件；不修改生产默认，不放宽Hard，不调用官方simulate/publish/challenge，不提交推送。
- 不启用子agent；本地计算worker只用于独立对局并行。

## 分层与数据隔离

开发集选择64个不同地图的代表场景，覆盖搜索后死亡、隐藏/非接触死亡、差一星输局、校准退化及胜局控制；一律双方换位128局。验证集另取128个不同地图的场景，256局，不参与规则选择。地图按实际地形哈希分组，同地图不跨集。全部1243场景此前已做过总体分析，验证集是规则开发隔离集，不称全新盲测。

## 单轮流程

1. 写入假设、机制、输入与源码哈希。
2. 机制分析先做单步反事实：同一帧仅替换一个finalGate允许的动作，前缀必须完全一致，后续沿用当前策略。Risk不接受可以作为诊断标签，不能自动当成应放宽Risk的证据；Hard不允许的动作不强制。
3. 收益按唯一对局计数；同局多个可恢复根不重复累加。反事实结果是该已观察对手轨迹下的经验潜力，绝非可部署策略收益。
4. 可执行候选只改变一个机制。先跑开发集：净得分至少+2局分，单方死亡和换位双负均不增加。未通过即停止，不观察验证结果调参。
5. 通过后跑地图隔离验证集：净得分>0，单方死亡和双负均不增加，搜索节点不超过同集基线2倍。未通过淘汰。
6. 通过后跑固定2486局：净得分>0、单方死亡和双负不增加，错误/超时/restore为0，才标记QUALIFIED_DIAGNOSTIC_CANDIDATE。需要生产移植及等价测试后才能另行采用，不能把诊断类替换视为生产修复。
7. 同分或零行为变化不算改善。记录挽回与破坏、动作变化率、节点和本地耗时；不得把不同轨迹的wall time当作同输入性能结论。

## 本次10轮预注册

| 轮次 | 假设与唯一变量 | 范围 |
|---|---|---|
| R01 | 搜索后死亡可能在更早单个合法动作上可恢复 | 开发集4个不同场景，死亡前2/5/9帧 |
| R02 | 最后敌不可见的死亡可能在更早单个动作上可恢复 | 同上 |
| R03 | 非接触阶段死亡可能在更早单个动作上可恢复 | 同上 |
| R04 | 差一星的输局可能在终局前单步改善 | 4场景，终局前12/24/40帧 |
| R05 | bomb phase校准后退化可能在终局前单步改善 | 4场景，终局前2/5/9帧 |
| R06 | 通用搜索128预算与生产特化搜索128预算逐动作等价 | 开发集128局；不计为策略收益 |
| R07 | 仅把已验证等价的搜索预算128提高到256 | 开发→验证→全量，门槛逐级 |
| R08 | 保留更安全的GO incumbent，阻止较差风险proposal覆盖 | rescue-go-veto，开发→验证→全量 |
| R09 | 非击毁终局采用精确星数胜负价值能改善近终局排序 | exactFrameTerminal，开发→验证→全量 |
| R10 | 非接触阶段采用可接受的路径前沿改善导航 | path-frontier，开发→验证→全量 |

R06不等价时，R07仍执行通用128/256的同实现内部诊断，但结论限定为MEASUREMENT_ONLY，不跨入生产基线资格链。每轮结果如为负或不可恢复仍算完成实验，不为凑正收益扩大样本或事后换阈值。其他执行错误不算完成，必须修正测量入口并重做受影响轮次。

## 产物与复现

`tools/agentank/diagnostics/efficient-tuning-campaign.js` 固化分组、身份、反事实前缀检查与晋级门。每个stage保存压缩逐局记录和结果；campaign manifest保存样本名单、协议哈希和runner哈希，rounds.json保存10轮结论。使用新的输出目录重放，禁止覆盖既有实验。

```sh
node tools/agentank/diagnostics/efficient-tuning-campaign.js <新的输出目录>
```
